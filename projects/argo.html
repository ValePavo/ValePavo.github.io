About the Project

ARgo is a mobile AR platform for advertising campaigns, delivering interactive augmented reality experiences across iOS and Android. The application supports multiple simultaneous campaigns, each with distinct 3D content, interactions, and branded experiences triggered via image recognition. Built with ARKit and ARCore for cross-platform coverage.

My Role

AR Developer

Hands-on developer in a team of 2–3, responsible for AR tracking integration, Unity content pipeline, native bridge architecture, and in-app UI across both platforms.

My Technical Contributions

Hybrid Native / Unity Architecture

Built a native iOS and Android host app that embeds Unity as a lightweight AR container, enabling fast in-app navigation without Unity startup overhead on each AR session.

Cross-Platform AR Tracking

Implemented and tuned ARKit and ARCore across both platforms, applying custom stability improvements to reduce tracking loss under the varied lighting conditions and surface types common in advertising contexts.

Multi-Campaign Content System

Designed a content management layer capable of loading and displaying multiple distinct AR advertising experiences within a single app, with independent 3D assets and interactions per campaign.

Performance Optimization

Profiled and optimized the rendering pipeline targeting the widest possible device range. Applied draw call batching, texture compression, and LOD strategies to maintain stable frame rates on mid-to-low-end Android hardware.

UI Implementation

Designed and implemented the in-AR UI layer within the Unity container and coordinated the native navigation experience across both iOS and Android.
