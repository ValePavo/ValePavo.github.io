About the Project

ExpertAR is a retail AR platform for iOS and Android that allows customers to visualize and interact with products in augmented reality directly from their mobile devices. Built on Vuforia for reliable image and object recognition in real-world retail environments, the application supports a multi-product catalog with independent AR experiences per item. The AR layer runs inside Unity, embedded within a native host application for fast and fluid in-app navigation.

Sole Developer

Full technical ownership as the only developer on the project — from architecture decisions to deployment on both iOS and Android. Responsible for the native integration layer, Unity AR pipeline, Vuforia tracking, content system, and UI.

My Technical Contributions

Hybrid Native / Unity Architecture

Designed the native iOS and Android host application that calls Unity as an embedded AR container, enabling smooth in-app navigation and reduced startup latency for each AR session.

Vuforia Tracking

Implemented and tuned Vuforia-based image and object tracking for retail product recognition, optimizing target databases and detection thresholds for real-world shelf and in-store environments.

Multi-Product AR Visualization

Built a content system to load and display AR experiences across a multi-product catalog, with independent 3D assets and interaction states per target and efficient runtime asset management.

Performance & Tracking Stability

Profiled and optimized the full pipeline for low-end devices, focusing on tracking robustness, frame rate consistency, and memory footprint management across the full product catalog.

UI Implementation

Designed and implemented the in-AR UI within the Unity container and the native navigation layer, maintaining a consistent experience across iOS and Android.
