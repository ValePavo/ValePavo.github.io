About the Project

An action game for PC and handheld consoles built on Unity's ECS/DOTS stack. The project features procedurally generated maps, large-scale enemy encounters managed through a fully data-oriented architecture, and a deep progression system including quests, skill trees, and per-enemy wave configuration. A significant portion of the development effort went into custom editor tooling to support fast iteration across all data-driven systems.

Gameplay Programmer

Core systems programmer responsible for the data-oriented architecture, procedural generation, navigation, enemy management, and editor tooling. Also contributed to game design.

My Technical Contributions

Procedural Map Generation

The core and most complex system of the project. Designed and implemented a procedural map generation pipeline built on ECS/DOTS, leveraging the Job System and Burst compiler for fully parallelized world construction at runtime. The system sustains 1000+ active enemies on screen at 40 fps on Steam Deck — without a dedicated optimization pass, leaving significant headroom for further gains.

Flow Field Navigation

Built a custom flow field navigation system from scratch as a replacement for Unity's NavMesh. Flow fields scale to large enemy counts with near-constant cost per agent, enabling dense encounters while keeping CPU overhead minimal.

Enemy Spawn & Management (ECS/DOTS)

Architected the full enemy lifecycle — spawn, state, behavior, and despawn — as ECS entities processed via Burst-compiled jobs. Enabled hundreds of active enemies with predictable, cache-friendly performance on both PC and handheld hardware.

VFX & Shading

Created custom shaders and VFX systems integrated with the data-oriented pipeline, ensuring visual quality and performance efficiency consistent with the constraints of handheld targets.

Quest System (FSM)

Designed and implemented a Finite State Machine architecture to manage quest lifecycle — tracking state transitions (inactive, active, completed, failed) and chaining conditions across multiple objectives. Paired with a custom editor tool for authoring and managing quests directly in scene, without code changes.

Editor Tooling

Built a suite of custom Unity editor tools covering the main data-driven systems: augments, character stats, enemy waves, skill trees, and the quest editor tied to the FSM system.

Game Design

Contributed to game design alongside the technical work, including progression systems, wave structure, and skill tree architecture — ensuring design intent was reflected directly in the data systems being built.
